# อัปเดตจาก v7 → v8

1. **สำรองข้อมูลฐานข้อมูล** ก่อนทุกครั้ง
2. ใน Supabase SQL Editor ให้ใช้ไฟล์ `schema.sql` ของ v8 ทับสคริปต์เดิม (คำสั่งสร้างโครงสร้างมี `IF NOT EXISTS`, เพิ่ม `booked_for`, ถอด unique ต่อผู้จอง, เพิ่ม unique สำหรับจองตนเอง และเปลี่ยน RPC)
3. หลัง Run ตรวจว่ายังมีข้อมูล v7 ครบ, `booked_for` ของรายการเก่าเป็น `self`, และ RPC `confirm_seat(text,text,text,boolean)` ใช้งานได้
4. เปิดแท็บใหม่ด้วยเว็บไซต์ v8 (v7 เก่าไม่ควรใช้ต่อเพราะ RPC เดิมถูกลบ)
5. ทดสอบบัญชี A จองตัวเอง + จองให้ B, แล้วบัญชี C ห้ามจองเลขที่ B ซ้ำใน LIVE

**ข้อควรทราบ**: การจองแทนใน LIVE ยังไม่มีขั้นตอนที่ผู้รับยืนยันคำยินยอม จึงเหมาะกับการใช้งานภายใต้กติกาห้องเรียนที่อนุญาตการจองแทนเท่านั้น ก่อนใช้จริงควรพัฒนาให้ผู้รับยืนยันหรือผู้ดูแลอนุมัติ และควรมีขั้นตอนร้องขอแก้ไขที่นั่ง
