# อัปเกรด v9 → v10 (ไม่ใช้อีเมลนักเรียน)

1. สำรองข้อมูล Supabase ก่อนทุกครั้ง และหยุดรับจองชั่วคราว
2. เปิด Supabase SQL Editor และรัน `supabase/upgrade-v9-to-v10.sql` **เพียงครั้งเดียว** (ไม่ต้องรัน `schema.sql` ใหม่)
3. อัปโหลดไฟล์เว็บไซต์ v10 ทั้งหมดไป GitHub Pages แล้วรอ Deploy
4. ใน Authentication → Providers เปิด Anonymous Sign-ins ไว้
5. ผู้ดูแลยังคงใช้อีเมล/รหัสผ่านและต้องมีรายการใน `classroom_admins`
6. ทดสอบรอบ TEST และ LIVE ด้วยสองอุปกรณ์: จองเลขที่เดิมซ้ำต้องไม่ได้, โต๊ะเดิมซ้ำต้องไม่ได้, จองแทนคนละเลขที่ต้องได้, การเปลี่ยนโหมดต้องไม่ขึ้น DELETE requires a WHERE clause

## ความปลอดภัย
ไม่มีการพิสูจน์ตัวตนนักเรียน: ใครทราบชื่อและเลขที่ก็อาจจองแทนได้ ให้ผู้ดูแลตรวจสอบและแก้ไขได้ และพิจารณาเปิดใช้งาน CAPTCHA / rate limiting ก่อนเปิดสาธารณะ
ระบบออนไลน์ยังไม่ได้ทดสอบกับ Supabase โปรเจกต์จริงของคุณ
