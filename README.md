# ClassroomHub M.4/11 — School portal

หน้า Welcome → ปุ่ม **เริ่มกันเลย** → เมนูหลัก 6 รายการ (2 เปิดใช้งาน, 4 Coming Soon)

## โครงสร้างไฟล์

- `index.html`, `portal.css`, `portal.js` — หน้าแรกและเมนูหลัก
- `booking/` — เว็บจองที่นั่ง **ต้นฉบับจาก ClassroomHub v10** (ไม่ได้แก้ผัง/ฟอร์ม/สไตล์)
- `seating/` — เว็บแสดงที่นั่งและระบบขอสลับที่นั่งที่ต้องรอแอดมินอนุมัติ

ลิงก์ภายในเมนูใช้ relative URL ดังนั้นทำงานได้ทั้ง GitHub Pages project site และโฮสต์ static ทั่วไป

## เปิดทดสอบบนเครื่อง

เปิด Terminal ในโฟลเดอร์นี้แล้วรัน:

```bash
python -m http.server 5500
```

เข้า `http://localhost:5500` กด **เริ่มกันเลย** เพื่อเปิดเมนู 6 ปุ่ม แล้วกดไปยังเว็บจองหรือเว็บผังที่นั่ง

## อัปโหลดไป GitHub และเปิด GitHub Pages

1. สร้าง repository ใหม่ชื่อ `classroomhub-m411` หรือใช้ชื่อที่ต้องการ
2. อัปโหลด **ไฟล์และโฟลเดอร์ภายใน ZIP** (ไม่ใช่อัปโหลด ZIP เป็นไฟล์เดียว) ให้ `index.html` อยู่ที่ root ของ repository
3. เข้า **Settings → Pages** ของ repo เลือก Deploy from a branch → `main` → `/(root)` → Save
4. ลิงก์เว็บไซต์จะมีรูปแบบ `https://USERNAME.github.io/classroomhub-m411/` (แทนชื่อผู้ใช้และ repository จริง)
5. ระบบจองและผังจะอยู่ที่ `/booking/` และ `/seating/` ภายใต้ลิงก์เดียวกัน

> GitHub Pages เผยแพร่เฉพาะเว็บ static ส่วนการแก้ไขข้อมูลร่วมกันต้องตั้งค่า Supabase เพิ่มเติม

## เชื่อม Supabase (ยังไม่ได้เชื่อมในไฟล์นี้)

- ตั้งค่า URL และ publishable key ของ Supabase **ใหม่** ใน `booking/config.js` และ `seating/config.js` ตามคำแนะนำของแต่ละระบบ
- ตั้งฐานข้อมูลระบบจองด้วย `booking/supabase/schema.sql` และอัปเกรดตาม `booking/UPGRADE-TO-V10.md` ตามที่เหมาะสม
- ตั้งฐานข้อมูลผังที่นั่งด้วย `seating/supabase/seatmap.sql` และอ่าน `seating/SETUP-SEATMAP.md` โดยละเอียด
- ระบบผังเริ่มว่าง 40 ที่นั่งและไม่ได้คัดลอกจากประวัติการจอง
- **สำคัญ:** `seating/` ไม่มีโหมดสาธิต หากไม่ได้เชื่อม Supabase ระบบจัดการข้อมูล/ขอสลับที่นั่งยังไม่สามารถใช้จริงได้
- ตั้งแอดมินที่ Supabase Auth เพียงหนึ่งบัญชี; ห้ามเก็บรหัสผ่านหรือ service_role key ใน GitHub
- ระบบจองจาก v10 ยังมี Local Demo เมื่อยังไม่ตั้งค่า Supabase ต้องตั้งฐานข้อมูลก่อนใช้งานจริง

## ความเป็นส่วนตัวของนักเรียน

หน้าแสดงผังจะเปิดให้อ่านรายชื่อได้แบบสาธารณะหากเปิด GitHub Pages และ Supabase public read ขออนุญาตโรงเรียนและผู้เกี่ยวข้องก่อนเผยแพร่ข้อมูลชื่อเต็มของนักเรียน และพิจารณาใช้ชื่อเล่นหรือลดข้อมูลที่แสดง

คำขอสลับที่นั่งที่กรอกชื่อกับเลขที่ยังไม่ใช่การยืนยันตัวบุคคลที่แข็งแรง ต้องให้แอดมินตรวจสอบความยินยอมของนักเรียนทั้งสองคนก่อนอนุมัติ
